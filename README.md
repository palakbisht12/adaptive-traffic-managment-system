
# Adaptive Traffic Management System

## Project Overview
An intelligent traffic management system that prioritizes roads based on emergency vehicles, waiting time, vehicle count, and traffic density.

## Member 1: Traffic Intelligence + DSA + OOP

### Modules
- `Road.h` – Manages road and traffic information.
- `Vehicle.h` – Stores vehicle details and emergency status.
- `Queue.h` – Implements a FIFO queue using a linked list.
- `Heap.h` – Implements a max-heap for road prioritization.
- `HashTable.h` – Supports road lookup using Road ID.
- `Sorting.h` – Sorts roads based on priority.
- `test.cpp` – Provides tests for project components.

## Technologies Used
- C++
- Object-Oriented Programming
- Data Structures and Algorithms
