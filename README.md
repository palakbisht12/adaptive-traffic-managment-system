# Adaptive Traffic Management System

## Phase 1

Phase 1 establishes the basic structure of our
Adaptive Traffic Management System.

### Files
- traffic.h - Shared contract and data structures
- traffic.cpp - Function implementations
- main.cpp - User interface

### Technologies
- C++
- OOP
- DSA

### Current Features
- Add vehicle
- Remove vehicle
- Send ambulance
- Show traffic status
- Run traffic cycle
- Show statistics
